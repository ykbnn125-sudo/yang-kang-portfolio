# Yang Kang · 个人作品集

React + Vite 实现的暖橙与暗色个人作品集，优先适配 PC 展示。

## 运行

在本目录打开终端（Node.js 20.19+ 或 22.12+）：

```sh
npm install
npm run dev
```

浏览器打开终端显示的地址，通常为 http://127.0.0.1:5173/ 。当前交付目录已安装依赖，也可以双击 `start-preview.cmd` 启动。关闭启动窗口可停止预览。

## 构建

```sh
npm run build
npm run preview
```

`dist/` 为构建输出。应通过 HTTP 服务访问，不能直接双击其中的 HTML。

## 已实现

- 全屏视频 Hero、导航、联系入口、中英文切换与语言记忆。
- 个人照片、介绍、工作及教育经历、联系方式与数据。
- 18 个完整项目与系列，磨砂玻璃卡片与重新排版的项目详情，支持 Escape 关闭。
- 4 项能力展示、工具列表、整屏联系页。
- 邮件和电话链接、邮箱复制、完整 PDF 入口。
- 视频暂停控制、减少动态效果偏好、键盘焦点样式与基础小屏适配。

## 内容与后续修改

内容来自用户提供的《作品集2026.10.31.pdf》。未添加获奖或客户评价等未经提供的信息。工作日期按 PDF 原文保留；“5 年”为作品集自述，“05”为 Tuoerqi 任职期间上市产品数量，“18”为本站整理的项目与系列数量。

- `src/main.jsx`：个人文案、双语内容、项目与经历数据、交互。
- `src/style.css`：配色、排版、间距、响应式样式。
- `public/assets/`：头像、作品图、完整 PDF 与视频。
- `public/assets/hero.mp4`：由作品集中的产品静帧制作的 10 秒缓慢推拉循环视频，并非原始产品实拍视频。后续可直接用正式视频替换同名文件；`hero.jpg` 是静态回退画面。

项目详情保留原 PDF 页面的英文文字；网站界面与项目简介支持中英文切换。当前版本仅在本地预览，尚未部署公网。完整页码对应关系见 CONTENT-INVENTORY.md。英文为默认界面，悬停或键盘聚焦项目卡片可揭开磨砂效果。
